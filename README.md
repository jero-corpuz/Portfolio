# Jero OS - Virtual Operating System Portfolio

A virtual operating system portfolio built with **Next.js 16**, **TypeScript**, **Tailwind CSS v4**, and **Aceternity UI**.

![Jero OS](https://jero-portfolio.netlify.app/_next/image?url=%2Fimages%2Favatar%2Favatar.jpg&w=384&q=75)

## 🚀 Features

- 🖥️ **Virtual Desktop & iPhone Views**: Responsive device auto-detection with smooth desktop glassmorphism window manager and mobile touch grid.
- 🎨 **Dynamic & Static Wallpaper Engine**: Interactive 3D WebGL wallpaper presets powered by Three.js & React Bits (`FloatingLines`, `Particles`, `Boxes`, `Wavy Canvas`, `Synthwave`, `Hacker Matrix`).
- 💻 **System Terminal Shell**: Interactive developer CLI shell for exploring technical capabilities with ASCII matrix progress bars (`jero@jero-os:~$`).
- 💼 **Aceternity UI Timeline**: Scroll-driven glowing career history timeline.
- 🚀 **Performance & Code-Splitting**: 100% WCAG-accessible, lightweight bundle loading via Next.js dynamic imports.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Vanilla CSS
- **Animations**: Framer Motion
- **3D Graphics & Shaders**: Three.js & OGL
- **Icons**: Lucide React

## 📦 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 🏗️ Production Build

To build the production bundle:

```bash
npm run build
```
